# Privacy Policy for Journal Lens

Effective date: July 28, 2026

Journal Lens is a browser extension that helps researchers view journal metrics and use explicit DOI-based lookup controls on supported academic websites.

## Data handled by the extension

Journal Lens may read article metadata from supported academic web pages, including journal names, article titles, DOI values, PMID values, and page URLs. This information is used only to identify publications, retrieve journal metrics, and provide user-initiated lookup or literature request actions.

Journal Lens may store extension settings locally in the browser, including display preferences, selected data sources, imported journal metadata, cached lookup results, and optional API keys entered by the user.

## External services

Depending on the user's settings and actions, Journal Lens may send publication names, DOI values, PMID values, article titles, or API keys to external services in order to retrieve journal metrics or literature metadata. These services may include OpenAlex, easyScholar, NCBI, ShowJCR metadata sources, and AbleSci.

The easyScholar API key, if configured, is stored locally in the user's browser and is sent only to easyScholar when the user enables easyScholar as a data source or performs a related lookup.

## Data not collected

Journal Lens does not sell user data. Journal Lens does not collect financial information, health information, personal communications, precise location, or full browsing history. Journal Lens does not use user data for advertising, creditworthiness, lending, or purposes unrelated to its academic lookup functionality.

## User control

Users can change extension settings, remove API keys, clear imported metadata, and uninstall the extension at any time through the browser's extension management pages.

## Contact

For privacy questions or extension support, please contact the developer through the support email listed on the extension store page.
